# ドール服パターンメーカー（アプリ）

ブラウザだけで動く型紙作成ツール。設計は [../05-design.md](../05-design.md)。

## 使い方

1. 「採寸を取り込む」→「指示文をコピー」→ 採寸画像と一緒に Claude アプリへ送る
2. Claude の返答をそのまま全部貼り付けて「取り込む」
3. 左の表で「推定」になっている値を、実物を測って直す（任意）
4. Tシャツの設定（布・開き・着丈・袖丈）を選ぶ
5. 「PDFを保存」→ **100%（実際のサイズ）で印刷**し、3cm の正方形を定規で測って確認する
   - 複数ページのときは、各ページの枠線で切りそろえて、右下の番号（行-列）の順に貼り合わせる

データはブラウザ内に保存される（他の端末には移らない）。別の端末で使うときは「JSONで保存」したファイルを取り込む。

## 開発

```bash
npm install
npm run dev        # 開発サーバー
npm test           # テスト（推定・作図・出力をサンプル5体で確認）
npm run build      # dist/ に書き出し
```
