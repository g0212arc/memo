# ドール服パターンメーカー

ドールのボディ採寸値から型紙を引き、**一度作った型紙を別ボディのサイズに合わせて自動で作り直す**ための
ブラウザツール。

> ステータス: **Tシャツ・タートルネック・パンツ・キャミソールワンピース・セーラートップス・Yシャツ・ジャケット・マント／ケープ実装済み**。アプリは [app/](app/)。

## 結論（ここまでで決まったこと）

| 論点 | 決定 | 理由 |
|---|---|---|
| 作図の考え方 | **採寸値をそのまま使う作図**（人間用原型の比率式は使わない） | ドールは胸囲とウエストの差などが人間と大きく違い、メーカーごとにもバランスが違う |
| 作り直しの方式 | **型紙を「寸法の式」で持つ（パラメトリック方式）を本体** | 体型差が大きいボディ間（大福体→甜瓜体など）でも正しく作り直せる |
| AI の使い方 | **ツール本体は AI を使わない**。採寸画像の読み取りだけ Claude アプリ（サブスク内）で行う | 利用ごとの課金を発生させない |
| 採寸の取り込み | **①: Claude アプリで JSON 化 → ツールに貼り付け** | 人の入力を最小にしたい |
| 対象アイテム | **Tシャツ → ノースリーブタートルネック → ハーフパンツ → スカート** | この順に作る |
| 既存型紙の読み込み | **作らない** | 既存の型紙がないため、すべてこのツールで引く |
| スマホ | **閲覧と PDF 保存だけ** | 編集は PC |
| サンプル5体 | **参考用** | 実際は手持ちのボディを実測して使う |
| 入力を減らす方針 | 足りない採寸値は**ツールが自動推定**し「推定値」と表示。人は気になる所だけ直す | 人の入力を最小にしたい |

## 全体の流れ

```
[採寸画像] ──Claudeアプリ（定型プロンプト）──▶ [JSON] ──貼り付け──▶ [ツール]
                                                                     │
                     ┌───────────────────────────────────────────────┘
                     ▼
     ボディ登録（不足項目を自動推定）
                     │
                     ▼
     型紙（式で定義）を選ぶ ──▶ ボディを切り替えると即再計算 ──▶ 原寸PDF / SVG / DXF
```
