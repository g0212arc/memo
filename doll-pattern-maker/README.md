## 結論（ここまでで決まったこと）

| 論点 | 決定 | 理由 |
|---|---|---|
| 作図の考え方 | **採寸値をそのまま使う作図**（人間用原型の比率式は使わない） | ドールは胸囲とウエストの差などが人間と大きく違い、メーカーごとにもバランスが違う |
| 作り直しの方式 | **型紙を「寸法の式」で持つ（パラメトリック方式）を本体** | 体型差が大きいボディ間（大福体→甜瓜体など）でも正しく作り直せる |
| AI の使い方 | **ツール本体は AI を使わない**。採寸画像の読み取りだけ Claude アプリ（サブスク内）で行う | 利用ごとの課金を発生させない |
| 採寸の取り込み | **①: Claude アプリで JSON 化 → ツールに貼り付け** | 人の入力を最小にしたい |
| 入力を減らす方針 | 足りない採寸値は**ツールが自動推定**し「推定値」と表示。人は気になる所だけ直す | 同上 |

## 全体の流れ

```
[採寸画像] ──Claudeアプリ（定型プロンプト）──▶ [JSON] ──貼り付け──▶ [ツール]
                                                                     │
                     ┌───────────────────────────────────────────────┘
                     ▼
     ボディ登録（不足項目を自動推定）
                     │
                     ▼
     型紙（式で定義）を選ぶ ──▶ ボディを切り替えると即再計算 ──▶ 原寸PDF / SVG / DXF
```
