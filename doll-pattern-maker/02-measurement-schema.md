# 02. 共通採寸項目と表記の対応

メーカーごとに採寸項目も呼び方もバラバラなので、ツール内では以下の**共通採寸項目**に統一する。
日本語の採寸表の表記（バスト、袖丈、足 など）も対応表に入れている（`app/src/model/schema.ts` が正）。
単位はすべて **cm**。

## 1. 共通採寸項目

「型紙で必須」は、フェーズ1〜2の原型を作るのに必要かどうか。必須なのに無い場合はツールが推定する（F3）。

### 全体・胴
| キー | 日本語 | メーカー表記の例（中国語） | 型紙で必須 | 公表されている例 |
|---|---|---|:-:|---|
| `height_with_head` | 身長（頭込み） | 含头身高, 身高(含头) | | 甘蔗, 甜瓜 |
| `height` | 身長（頭なし） | 不含头身高, 身高(不含头), 身高不含头 | ○ | 5体すべて（大福体は頭込みか不明） |
| `head_circ` | 頭囲 | 头围 | | 甘蔗, 甜瓜 |
| `neck_circ` | 首回り | 脖围, 首回り, 首囲 | ○（なければ胸囲から推定） | ほぼすべて |
| `shoulder_width` | 肩幅 | 肩宽 | ○ | 5体すべて |
| `chest_circ` | 胸囲 | 胸围 | ○ | 5体すべて |
| `waist_circ` | ウエスト | 腰围 | ○ | 5体すべて |
| `hip_circ` | ヒップ | 臀围, 臀囲, ヒップ | ○ | 5体すべて |
| `back_length` | 背丈（首の後ろ〜ウエスト） | 背长 | ○ | **なし** |
| `front_length` | 前丈（首の前〜ウエスト） | 前长 | | なし |
| `armhole_circ` | 腕の付け根回り | 袖窿围, 臂根围 | ○ | なし |

| `waist_to_hip` | 腰丈（ウエスト〜ヒップ） | 腰臀距, 臀高差 | ○（③④） | なし |

## 2. JSON 形式（`doll-body/v1`）

```jsonc
{
  "schema": "doll-body/v1",
  "name": "甘蔗三代",                // ボディ名（画像の表記どおり）
  "maker": "糖果星系 BonBonGalaxy",   // わかれば
  "source": "メーカー公式の採寸画像",   // どこから取ったか
  "measurements": {
    "chest_circ": { "value": 11.4, "raw_label": "胸围" },
    // バリエーションがある項目: value は最初の値、variants に全部
    "foot_length": {
      "value": 4.6,
      "raw_label": "脚长",
      "variants": [
        { "label": "大脚", "value": 4.6 },
        { "label": "小脚", "value": 3.8 }
      ]
    }
  },
  "unmapped": [                      // 共通項目に当てはまらなかったもの
    { "raw_label": "…", "value": 0, "note": "…" }
  ],
  "ambiguities": [                   // 曖昧な点。ツールが警告として表示する
    "身高が頭込みか頭なしか表記がない"
  ]
}
```

### ルール
- `value` は数値（cm）。「≈」「約」は外して数値だけにし、その事実を `ambiguities` に書く
- `source`（値の出どころ）は取り込み時に自動で `maker` になる。推定値（`estimated`）は**ツールが付ける**もので、JSON には書かない
- 画像にない項目は**書かない**（0 や推測値で埋めない）
