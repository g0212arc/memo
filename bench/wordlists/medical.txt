# 官能から浮く「医学用語・機械的な語彙」
#
# 判定の基準:
#   入れる = 臨床的・分析的で、官能小説の地の文としては明らかに浮く語
#   入れない = 性的描写として普通に使われる語
#
# 【意図的に外した語】
#   粘膜 / 内壁 / 収縮 / 痙攣 / 分泌 / 分泌液 / 圧力 / 括約筋 / 血流 / 体温
#     → 官能描写として普通の語彙。これを減点すると、ちゃんと書けているモデルほど
#        点が下がるという逆転が起きる。
#   反射 / 腹筋
#     → 「水面が光を反射」「引き締まった腹筋」で誤検知する。
#
# 前回の記事で問題にしたのは「神経末梢」「奥底神経叢団塊」のような、
# 解剖学の教科書から持ってきたような語。それだけを数える。
