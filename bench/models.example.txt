# OpenRouter で回すモデル（1行1モデル、# 以降はコメント）
# 使うときは models.txt にコピーしてください（models.txt は git 管理外）:
#   cp models.example.txt models.txt
#
# 書式:  モデルID              … OpenRouter に提供元を任せる
#        モデルID@プロバイダ    … 提供元を固定する（フォールバックなし）
#
# 同じモデルでも提供元によって量子化(fp8/fp4)が違い、出力も変わります。
# 固定しないと呼び出しごとに提供元が変わって比較にならないことがあるので、
# 厳密に比べたいものは @ で固定してください。提供元の一覧は
#   curl https://openrouter.ai/api/v1/models/<モデルID>/endpoints
# で確認できます。実際に呼べるかは check_models.py で事前に点検できます。
