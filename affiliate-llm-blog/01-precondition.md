# 01. 着手前に潰しておくこと（規約リスク）

リンクを置く前に片付けないと、**アカウント停止で全部ゼロになる**ポイントが2つある。
ここだけは省略しないこと。

---

## リスク1: NSFWコンテンツと Amazon／楽天アフィは共存できない

Amazonアソシエイト・プログラムは、参加をお断りするサイト例として
**「性的に露骨な内容を含む、または助長するサイト」**を明記している。
審査に落ちるだけでなく、運用開始後に発覚した場合はアカウント停止＋未払い報酬の失効になりうる。
楽天アフィリエイトも同様にアダルトコンテンツを禁止している。

現状のブログは「日本語NSFW小説・RP用途のローカルLLM検証」であり、
**出力サンプルを載せている記事はこの条項に触れる可能性が高い。**

### 対策の選択肢

**案A: 同一ブログ内で棲み分け**
- NSFW出力サンプルを別記事に切り出し、その記事にはリンクを置かない
- 弱点: 同一ドメイン内なので「サイト」としては1つと見なされうる。リスクは減るが消えない

**案B: ブログを2つに分ける ← 推奨**
- はてなブログは1アカウントで複数ブログを持てる（無料版3つ／はてなブログPro 10個）
- **ブログA（機材・検証）**: アフィあり。ベンチ、VRAM使用量、量子化比較、tok/s、電気代、セットアップ手順。
  「日本語の指示追従性」「キャラの一貫性が保たれるか」といった**評価は書く**が、生の出力サンプルは載せない
- **ブログB（出力サンプル・作品）**: アフィなし。Aへ「検証環境と数字はこちら」と1リンクだけ置く
- 移行作業は既存記事の棚卸し込みで60〜90分

**案C: NSFW記事を残したまま、アフィを諦める**
- 一番安全だが、資産の大半が使えなくなる

### 判断: 案B

持っている検証データの価値は**「機材と数字」の側**にある。そこだけ切り出しても記事として十分成立するし、
むしろ検索から来る読者の目的とも一致する。NSFWを分離しても記事の価値は落ちない。

> 補足: ASPによって基準は異なる。A8.net や もしもアフィリエイト は案件ごとの規定。
> アダルト可のASPもあるが、単価と手間が方針に見合わないので今回は使わない。

## リスク2: ステマ規制（景品表示法）

2023年10月1日施行の景表法の指定告示により、**広告であることを隠した表示は違反**になる。
アフィリエイトリンクを含む記事には広告表記が必要。各ASPも掲載者に対して「PR」「広告」等の表記を要請している。

### 必須対応

1. **記事のファーストビュー（＝冒頭、タイトル直下）に広告表記**を1行入れる
   - 記事下や小さい注釈ではなく、最初に目に入る位置であることが要件
2. **Amazonアソシエイト規約が別途要求する定型文**をサイトに掲示する

文言は [templates/disclosure.html](templates/disclosure.html) に用意した。そのまま貼る。

## 着手チェックリスト（初月にやること）

順番どおりにやる。上から2つが終わるまで、リンクは1つも置かない。

- [ ] **ブログBを作成**し、NSFW出力を含む記事を移動（元URLには移転先リンクだけ残す）
- [ ] ブログAに**プライバシーポリシー／免責ページ**を作成（アフィ表記・Amazonアソシエイト定型文・アクセス解析の記載）
- [ ] **楽天アフィリエイト**を有効化（楽天会員なら審査なしで即使える。まずこれで全部埋める）
- [ ] **もしもアフィリエイト**に登録（Amazon・楽天をまとめて扱える。「かんたんリンク」が便利で、Amazon直の審査が通らない場合の保険にもなる）
- [ ] **Amazonアソシエイト**を申請（ブログAのURLで）
- [ ] **A8.net** に登録（高単価枠用。当面は寝かせておいてよい）
- [ ] はてなブログ 設定 → 詳細設定 に AmazonアソシエイトID／楽天アフィリエイトID を登録
      （編集画面の「商品」ボタンから貼るだけで自分のIDが入るようになる）
- [ ] 記事冒頭の広告表記を、デザインCSS または 各記事の先頭に設置

### 注意: Amazonアソシエイトの承認条件

Amazonアソシエイトは申請後、**180日以内に3件の適格販売がないと本承認されない**。
つまり「登録したのに売れない → 承認されない」というループがある。

対策: **最初は楽天アフィリエイトで全部埋める**。楽天は審査がなく即日使える。
Amazonは承認が下りてから、あるいは もしもアフィリエイト経由で差し替える。
これなら Phase 0 の「発生1件」を最短で取りにいける。
