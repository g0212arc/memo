# 追記チェックリスト（1記事あたり5〜7分）

記事を1本追記するたびに、これを上から順に。

## 貼る前

- [ ] この記事はNSFW出力を含んでいないか？（含むなら**リンクを置かない**／ブログBへ移す）
- [ ] 記事タイプ別の配置表（[02](../02-placement.md)）を確認したか？

## 貼る

- [ ] 記事冒頭に広告表記があるか（自動挿入設定済みならスキップ）
- [ ] 記事末尾に型1ブロックを設置（[gear-box.html](gear-box.html)）
- [ ] 各商品の**型番**をリンクテキストにしたか（「こちら」になっていないか）
- [ ] 各商品に**理由を1行**書いたか
- [ ] うち1つに**短所**を書いたか
- [ ] リンク総数は6個以内か

## 貼ったあと（音読して確認）

- [ ] リンクを外しても文章として成立するか？
- [ ] 「買ってほしい」と思って書いた文が1つでもないか？
- [ ] 普段の記事と口調が変わっていないか？
- [ ] 数字（tok/s、GB、W、円）が入っているか？

## 月次（5分）

- [ ] 成果の数字をメモに記録（分析はしない）
- [ ] リンク切れ・在庫切れがないか確認
