## 決定事項（結論から）

1. **既存記事への追記のみ**で運用する。新規執筆は原則しない（例外は「機材まとめ」ハブ記事1本だけ）
2. **NSFW出力を含む記事とアフィリンクを置く記事は分離する**（規約リスク回避。これが最優先）
3. 物販（Amazon／楽天）を土台に、**高単価枠を1つだけ**上乗せする
4. 初期目標は月3万円ではなく **「Claude Pro 1本＝月3,000円」** から段階的に上げる
5. 作業時間は **月35分**（追記30分＋数字チェック5分）。超えたら方針が間違っている

## 収益の現実的な試算

先に正直な話をしておく。**「既存記事にリンクを置くだけ」で月3万円は、物販アフィだけでは届かない。**

楽天アフィリエイトの料率は概ね2%・1商品あたり成果上限あり、Amazonのパソコン／パーツ系も2〜4.5%程度で上限がある。
中古RTX 3060（3万円）が1台売れて成果は数百円〜1,000円。ここが天井を決めている。

| 月間PV | クリック（CTR 2%） | 成約（CVR 3%） | 平均単価400円での月額 |
|---:|---:|---:|---:|
| 3,000 | 60 | 約2件 | 約800円 |
| 10,000 | 200 | 約6件 | 約2,400円 |
| 30,000 | 600 | 約18件 | 約7,200円 |

→ **物販だけの現実的な天井は月2,000〜8,000円。**

月3万円との差分を埋めるのは「高単価枠」。GPUクラウド／VPS系のASP案件は1件2,000〜10,000円で、
月3〜5件で3万円に届く。ただし「置けば出る」ものではなく、置き場所（記事の文脈）が合っているかが全て。
→ 選定基準は [03-link-candidates.md](03-link-candidates.md) に。

## 段階目標

| フェーズ | 期間 | 目標 | 到達手段 |
|---|---|---|---|
| Phase 0 | 1ヶ月目 | **発生1件**（金額は問わない） | 仕組みが動くことの確認だけ |
| Phase 1 | 3ヶ月 | 月3,000円（Claude Pro代） | 既存記事への追記のみで到達可能 |
| Phase 2 | 6ヶ月 | 月8,000〜10,000円 | 上記＋高単価枠1つ |
| Phase 3 | 12ヶ月 | 月30,000円＋中古3060 1枚 | PVの自然増と高単価枠の当たり待ち |

Phase 1 までは追記だけで届く。Phase 2 以降は待ちの時間が長い。**焦って手法を増やさないこと**が
この仕様書で一番守ってほしいルール。
