# 05. X（旧Twitter）の運用

## 方針

Xは**「送客する場所」ではなく「置いておく場所」**。
毎日の投稿・リプ周り・バズ狙いはしない。プロフィールと固定ポストだけ整えて、あとは触らない。

---

## プロフィール文案（160字以内）

### 案A: 現状維持寄り（**推奨**）
```
RTX 3060 12GB でローカルLLMを動かしている会社員。日本語モデルの実測・量子化比較・VRAMの限界をブログに書いています。ドールとイラストも。

検証環境と記事 → [ブログAのURL]
```
既存フォロワーとの断絶がなく、趣味の部分も残る。いまの温度に一番近い。

### 案B: 機材寄り（検索流入・機材目当ての読者向け）
```
ローカルLLM検証（RTX 3060 12GB / VRAM 12GB で何ができるか）。tok/s・VRAM使用量・電気代を実測して記録しています。営業も案件募集もしていません。

記事一覧 → [ブログAのURL]
```
「営業も案件募集もしていません」の1文が、逆に信頼として効く。

### 案C: 最短
```
3060 12GB でローカルLLM。実測値だけ書くブログ → [URL]
```

### プロフィールのルール
- **URLは1つだけ。** ブログAのトップ、または **M2「動くモデル一覧」**（→ [04-money-pages.md](04-money-pages.md)）
- **生のアフィリンクをプロフィールに直接置かない**（規約的にもグレーで、露骨に見える）
- リンクツリー系サービスは使わない（それだけで発信の性格が変わって見える）

---

## 固定ポスト案

```
RTX 3060 12GB でローカルLLMをどこまで動かせるか、実測をまとめています。

・14B Q4 の tok/s と VRAM使用量
・量子化ごとの日本語の劣化具合
・実測の消費電力と、月の電気代

構成と数字はこちら → [M2「RTX 3060で動くモデル一覧」のURL]
```

固定ポストの飛び先は **M2「RTX 3060 12GBで動くモデル一覧」** にする（→ [04-money-pages.md](04-money-pages.md)）。
そこが型1ブロックの完全版になっているので、導線はこれ1本で足りる。

---

## Xでやらないこと

- 毎日投稿、リプ周り、伸ばすためのバズ狙い
- **アフィリンクの直貼り**
- 「稼ぎ方」「AI副業」系の発信
  → 読者層が入れ替わり、いまのフォロワーが離れる。実測ブログとしての信頼も落ちる
- 反応がなかったポストを消して投げ直す、といった運用

## Xでやること（月1回・5分）

- 記事を追記した月だけ、**1ポストだけ**「◯◯を追記しました」と投げる。それ以上はしない
