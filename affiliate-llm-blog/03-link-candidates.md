# 03. リンク候補と選定基準

## 選定基準 — この5つを **全部** 満たすものだけ置く

1. **自分が実際に持っている／使ったことがある**
2. 記事の中で**自然に型番を書く必然性がある**
3. **型番が確定している**（「中古GPU」ではなく「RTX 3060 12GB」）
4. 読者がその記事を読む動機と、その商品を買う動機が**同じ**
5. **リンク切れしにくい**（中古の個別出品ではなく、ショップの商品ページへ）

満たさないものは置かない。**「単価が高いから」だけの理由で置かない。**
これが読者の信頼を一番早く削る。

---

## 大前提: Amazon と 楽天 の使い分け

**Amazonアソシエイトは2024年8月7日に「1商品あたり紹介料1,000円」の上限を廃止した。**
楽天アフィリエイトは**1商品1個につき1,000円の上限が残っている**。

| | 料率 | 1商品あたり上限 | 高額品 |
|---|---:|---|---|
| **Amazon** | 2%前後（PC・パーツ） | **なし**（2024/8/7〜） | 20万のPC → 約4,000円 |
| **楽天** | 2〜4% | **1,000円** | 20万のPC → 1,000円で頭打ち |

> ### 使い分けルール（これだけ覚える）
> **高額品（PC本体・上位GPU）は Amazon。安価な周辺機器は楽天でもよい。**

**もしもアフィリエイト経由**にすると Amazon／楽天／Yahoo を1つのリンクにまとめられ、
読者が普段使う店で買えるので成約率が上がる。W報酬ボーナスもあるので、
Amazon直より実入りが良いことが多い。**基本はもしも経由でよい。**

## エンジン1 — PC本体（最重要・単価2,000〜5,000円）

前の版ではここが抜けていた。**上限撤廃によって、これが物販で最も効く枠になった。**

| 商品 | 想定成果 | 置く記事 |
|---|---:|---|
| **中古ゲーミングPC（3060搭載）** | 2,000〜3,000円 | M1、M2、M3 |
| **新品BTOゲーミングPC** | 3,000〜5,000円 | M1 |
| 上位GPU単体（4060 Ti 16GB 等） | 1,000〜1,500円 | M3 ※下記の条件つき |

**文脈が完全に一致している。** 「3060でLLMを動かしたい」読者にとって、
3060搭載の中古ゲーミングPCは**GPU単体を買うより現実的な選択肢**であることが多い（電源・ケース・CPU込みのため）。
読者の多くはこれを知らないので、記事として価値があり、かつ**1台がパーツ10個分**になる。

> **上位GPUの扱い:** 持っていない製品にリンクを貼るのは禁止（下記）。
> ただしM3で「4択の1つ」として実測なしに触れる場合は、
> **「持っていないので試せていない」と明記したうえでリンクは貼らない**。
> ここを曖昧にすると、実測ブログとしての信頼が一撃で消える。

## エンジン2 — VPS・GPUクラウド（単価3,000〜10,000円）

**月3〜5万の可否を決めるのはここ。** 無料試用で成果になる案件を優先する。

| 候補 | 単価目安 | 着地させる記事 |
|---|---:|---|
| **GPUクラウド／AIサーバー** | 3,000〜10,000円 | **M3**（VRAM不足の4択） |
| **VPS**（ConoHa、Xserver、さくら等） | 3,000〜10,000円 | M3、M4 |
| 電力プラン切替 | 3,000〜8,000円 | M4 ※自分が切り替えたときだけ |

### 実務上の注意

- 高単価案件には**即時提携と審査ありがある**。NSFW分離（→ [01](01-precondition.md)）が済んでいれば通る可能性は高い
- **無料試用系は否認されにくい**が、電力切替は開通まで2〜3ヶ月かかり成果確定が遅い
- **提携は3〜5件申請しておく。** 案件は終了・単価改定があるので、1本足りだと止まったとき丸ごと消える

## エンジン3 — パーツ物販（土台・単価300〜1,000円）

| 商品 | 想定成果 | 置く記事 | 備考 |
|---|---:|---|---|
| **RTX 3060 12GB**（中古・整備済み） | 〜600円 | 全記事 | 楽天の中古PCショップ／Amazon整備済み品。個別出品には貼らない |
| **ATX電源 650〜850W** | 300〜500円 | 構成・電力 | 2枚差しを見据えるなら850W |
| **NVMe SSD 2TB** | 300〜600円 | 全記事 | **相性が非常に良い。**「GGUFは1本30GB」の話とセットで |
| **DDR4／DDR5 32〜64GB** | 400〜800円 | オフロード検証 | CPUオフロード・mmapの話とセット |
| **ワットチェッカー** | 40〜100円 | M4 | 単価は低いが**記事との一致度が最高**。よく売れる |
| GPUサポートステー／PCIe電源ケーブル／ケースファン | 少額 | 構成・発熱 | ついで買い枠 |

### 安価品を捨てない理由 — Amazonのクッキーは24時間

リンクを踏んだ読者が、その後**24時間以内に買った別の商品**も成果になる。
ワットチェッカーのような「踏むハードルが低い安価品リンク」は、
**高額品への入口**として機能する。単価だけ見て外さないこと。

## エンジン4 — AdSense（任意・完全放置）

| | |
|---|---|
| 収益 | 技術ブログのRPMは概ね200〜500円／1,000PV → 月1万PVで**2,000〜5,000円** |
| 手間 | **一度貼れば以後ゼロ。**「軽いアフィ」の理想形 |
| 絶対条件 | **NSFW分離が完了していること。**AdSenseはアダルト判定が最も厳格で、通らないだけでなく後から停止もある |
| トレードオフ | 広告が入るぶん読み心地は落ちる。「売り込み感を出さない」方針とは少し逆を向く |

**判断は後回しでよい。** 5本の収益ページが揃ってPVが見えてから決める。
月1万PVに届いていないなら、貼る価値より読み心地の損失のほうが大きい。

## 将来の一手 — 2枚差し

PCIe 4.0 ライザーケーブル／オープンフレーム／1000W級電源。

> **「3060を2枚差しでVRAM 24GBにしてみた」記事は書く価値が高い。**
> 日本語の実測情報がほぼない／検索需要はある／M3（最高単価の記事）の中身を強化できる／
> 何より**自分が2枚目を買う理由そのもの**になる。
> 5本を書き終えたあと、趣味として書く1本はこれがいい。

---

## 置かないもの（禁止リスト）

- **自分が使っていないGPU・PCを「こっちのほうがいい」と紹介する**
  → 実測ブログの信頼性の根幹が崩れる。書くなら「持っていないので試せていない」と明記し、**リンクは貼らない**
- **中古の個別出品**（在庫1点もの）→ リンク切れ＋読者が損をする
- 情報商材・副業系・投資系 → 単価は高いが読者層と一致しない
- **レンタルサーバー案件を「ブログの始め方」文脈で置く**
  → 単価は高い（1件1万円超）が、ジャンルが変わり読者層が入れ替わる。VPSとは別物として扱う
- ブログと関係ない汎用ASP案件（クレカ、脱毛、光回線など）
- NSFW関連の商品・サービス（→ [01](01-precondition.md)）
