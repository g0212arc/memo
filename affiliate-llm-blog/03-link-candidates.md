# 03. リンク候補と選定基準

## 選定基準 — この5つを **全部** 満たすものだけ置く

1. **自分が実際に持っている／使ったことがある**
2. 記事の中で**自然に型番を書く必然性がある**
3. **型番が確定している**（「中古GPU」ではなく「RTX 3060 12GB」）
4. 読者がその記事を読む動機と、その商品を買う動機が**同じ**
5. **リンク切れしにくい**（中古の個別出品ではなく、ショップの商品ページ／整備済み品ページへ）

満たさないものは置かない。**「単価が高いから」だけの理由で置かない。**
これが読者の信頼を一番早く削る。

---

## Tier 1: 確実に置くもの（すでに使っている／記事に登場する）

| 商品 | 想定成果 | 置く記事 | 備考 |
|---|---:|---|---|
| **RTX 3060 12GB（中古・整備済み）** | 〜1,000円 | 全記事 | 楽天の中古PCショップ／Amazon整備済み品。個別出品ではなくショップの商品ページへ |
| **ATX電源 650〜850W** | 300〜500円 | 構成・電力記事 | 2枚差しを見据えるなら850W。実際に使っている型番で |
| **NVMe SSD 2TB** | 300〜600円 | 全記事 | **相性が非常に良い。**「GGUFは1本30GB」の話とセットで書く |
| **DDR4／DDR5 32〜64GB** | 400〜800円 | オフロード検証記事 | CPUオフロード・mmapの話とセット |
| **ワットチェッカー**（サンワサプライ TAP-TST8 等） | 40〜100円 | 電気代記事 | 単価は低いが**記事との一致度が最高**。よく売れる |
| **GPUサポートステー** | 30〜80円 | 構成記事 | ついで買い枠 |
| **PCIe補助電源ケーブル／変換** | 少額 | 構成記事 | ついで買い枠 |
| **ケースファン** | 少額 | 発熱・エアフロー記事 | ついで買い枠 |

単価の低いもの（ワットチェッカー、ステー）は軽視しない。
**件数が出ると Amazonアソシエイトの承認条件（180日で3件）を満たしやすい**という実務上の意味がある。

## Tier 2: 2枚目を買ったら追加するもの

| 商品 | 置く記事 |
|---|---|
| PCIe 4.0 ライザーケーブル | マルチGPU記事 |
| オープンフレーム／マイニングフレーム | マルチGPU記事 |
| 1000W級電源 | マルチGPU記事 |

> **「3060を2枚差しでVRAM 24GBにしてみた」記事は書く価値が高い。**
> 日本語の実測情報がほぼない／検索需要はある／アフィとの相性が最高／
> 何より「自分が2枚目を買う理由」そのものになる。
> [06-operations.md](06-operations.md) の「唯一の新規記事」枠を、将来ここに使ってもよい。

## Tier 3: 高単価枠（A8.net 等・**まず1つだけ**）

選定基準: **無料登録／無料お試しで成果になるもの** ＞ 有料成約が条件のもの

| 候補 | 単価目安 | 合う文脈 | 判定 |
|---|---:|---|---|
| GPUクラウド／AIサーバー（ConoHa、さくら等） | 2,000〜10,000円 | 「12GBでは足りないモデルを試したいとき」 | **◎ 最初の1枠はこれ** |
| VPS | 2,000〜8,000円 | 常時稼働・API化 | ○ 2枠目の候補 |
| 光回線／電気料金比較 | 10,000〜20,000円 | 電気代記事 | △ 単価は高いが文脈が遠い。無理に置かない |
| 技術書・オンライン学習 | 数百円 | 学習系記事 | △ 文脈は近いが単価が低い |

**判断: 最初はクラウドGPU／VPSを1枠だけ**、「VRAM不足」または「電気代」の記事に置く。
3ヶ月効果を見てから2枠目を検討する。

## 置かないもの（禁止リスト）

- **自分が使っていないGPU**（RTX 4060 Ti 16GB など）を「こっちのほうがいい」と紹介する
  → 実測ブログの信頼性の根幹が崩れる。書くなら「持っていないので試せていない」と正直に書き、**リンクは貼らない**
- **中古の個別出品**（在庫1点もの）→ リンク切れ＋読者が損をする
- 情報商材・副業系・投資系 → 単価は高いが読者層と一致しない。フォロワーが離れる
- ブログの内容と関係のない汎用ASP案件（クレジットカード、脱毛など）
- **NSFW関連の商品・サービス**（→ [01-precondition.md](01-precondition.md) の規約リスク）
