# 07. 運用ルール

## 時間予算 — 「軽さ」の位置を1回だけ動かす

月3〜5万を目標にすると、月35分では届かない。ただし**増えるのは初期の5ヶ月だけ**で、
そのあとは元の月35分に戻る。**毎月の負担は変わらず、有限の作り込みを先に払う**という形。

| 期間 | 月あたり | 内訳 |
|---|---:|---|
| 1〜2ヶ月目（基盤） | **2〜3時間** | 初期セットアップ。1回で終わる |
| 3〜7ヶ月目（収益ページ） | **月2時間** | 収益ページ1本（90〜120分）＋ 月次30分 |
| 8ヶ月目〜 | **月35分** | 追記30分＋数字チェック5分。**元に戻る** |

初期投資は合計 **8〜10時間**。週末の午後5回ぶんで、これを超えたら設計が間違っている。

## 初期セットアップ（1〜2ヶ月目・合計4〜5時間）

| # | 作業 | 目安 |
|---|---|---:|
| 1 | ブログBを作り、NSFW出力を含む記事を移動（→ [01](01-precondition.md)） | 60〜90分 |
| 2 | **はてなブログPro＋独自ドメイン**（→ [01](01-precondition.md)） | 40分 |
| 3 | ASP登録・はてなへのID設定。**高単価案件は3〜5件申請** | 45分 |
| 4 | プライバシーポリシー／免責ページ作成 | 20分 |
| 5 | サイドバー「検証環境」モジュール設置 | 15分 |
| 6 | 記事冒頭の広告表記を自動挿入設定 | 15分 |
| 7 | アクセス上位**5記事だけ**に型1ブロックを設置 | 30分 |

7 は上位5記事だけでよい。全記事に一気に入れようとすると、そこで力尽きる。

## 収益ページ期（3〜7ヶ月目・月2時間）

**月1本だけ書く。** 順番と中身は [04-money-pages.md](04-money-pages.md) のとおり。

| 月 | 書く記事 |
|---|---|
| 3ヶ月目 | **M2** 動くモデル一覧（既存の数字を集約するだけ） |
| 4ヶ月目 | **M3** VRAM不足の4択 ← **単価最高。早く出して順位を育てる** |
| 5ヶ月目 | **M1** PCの選び方 |
| 6ヶ月目 | **M5** ローカル vs 課金 |
| 7ヶ月目 | **M4** 電気代 |

書いたら、**既存の検証記事から内部リンクを1行ずつ張る**（型1ブロックの下に）。これが5分。

### 速く書かないこと

5本を1ヶ月で全部書いても到達は早まらない。**検索順位の安定に3〜6ヶ月かかる**ので、
早く出したぶんだけ待ち時間が長く取れる月1本ペースが最適。急ぐ理由がない。

## 月次ルーチン（30分・全期間を通して）

1. **5分** — 成果の確認。ダッシュボードの数字をメモに残すだけ。**分析はしない**
2. **5分** — リンク切れ・**案件終了**のチェック。高単価案件は終了・単価改定があるので、ここだけは毎月見る
3. **20分** — 既存記事1〜3本に型1ブロックを追加／更新。1本5〜7分。終わらなければ翌月

## やらないことリスト

- 毎日の投稿・リール・TikTok・YouTube
- LINEリスト構築、メルマガ
- note販売、有料記事、セールスレター
- SEO狙いの記事量産、キーワード調査
- ジャンルを広げる（AI副業、稼ぎ方、ツール紹介）
- **収益ページを6本目以降に増やすこと**（5本で打ち止め。6本目は趣味として書く記事）
- 読者の質問に必ず答える運用（気が向いたときだけ）
- **成果が出ない月に「テコ入れ」すること**（3ヶ月は触らない）
- **収益が届かないことを理由に、手法を増やすこと**

最後の2つが一番大事。これまで見送った手法（リール量産、リスト構築、note設計）は、どれも
「月数十万を狙う代わりに、毎日の作業を前提にする」設計だった。
**この仕様は、単価と着地点の設計だけで月3〜5万を取りにいく**もので、作業量では取りにいかない。
だからそれらは要らないままでいい。

## 中止・見直しの条件

| 条件 | 対応 |
|---|---|
| **記事を書くのが楽しくなくなった** | **即座に全部止める。これが最優先の中止条件** |
| 収益ページ5本を書いて6ヶ月、月1万円に届かない | 着地点ではなく**PVが足りない**。M2/M3の検索順位を確認し、それでもダメなら物販だけ残して撤収 |
| 高単価案件が承認されない／終了した | 別案件に差し替える。ここが止まると3〜5万は届かないので、提携は常に3件以上維持 |
| 6ヶ月やって発生が1件もない | 読者に買う場面がない。物販は撤収し、AdSenseだけ残す |
| 規約が変わり NSFW／AI関連の扱いが変わった | 該当リンクだけ外す。ブログの構成は変えない |
| 月2時間で回らなくなった | 収益ページの執筆を止め、月35分の追記だけに戻す。**目標を下げるほうが正しい** |

## 判断に迷ったときの基準

> ### 「これは、検証記事を書くついでにできることか？」
>
> **Yes → やる ／ No → やらない**

| Yes | No |
|---|---|
| 既存記事に型1ブロックを足す | アクセス解析を見てキーワードを調整する |
| 収益ページ5本（既存データの再編成） | 6本目以降の収益ページ |
| 2枚差しの検証記事（どのみち自分がやりたいこと） | 売れ筋商品を調べてリンクを増やす |
| 買った電源のレビュー記事 | 案件のために持っていない製品を紹介する |
